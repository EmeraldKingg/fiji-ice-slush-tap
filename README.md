🥤 Fiji Ice Slush Tap

An interactive mini-game inspired by Fiji Ice, where players test their timing and accuracy by pouring slush into a moving cup.

🔗 Live Demo: https://emeraldkingg.github.io/fiji-ice-slush-tap/

🎮 About the Game

Fiji Ice Slush Tap is a browser-based mini-game built around a simple but engaging challenge.

Players must tap at the right moment to release slush from a moving nozzle and land it inside a cup. The objective is to complete six successful pours. As players progress, the nozzle moves faster, making each pour more challenging.

✨ Features

* Interactive tap-to-pour gameplay.
* Moving slush nozzle.
* Six-pour gameplay objective.
* Increasing difficulty as the game progresses.
* Visual game interface inspired by Fiji Ice branding.
* Keyboard support using the Spacebar.
* Lightweight browser-based experience.

🛠️ Technologies Used

* HTML5 – Game structure and layout.
* CSS3 – Styling, visual elements and interface design.
* JavaScript – Game mechanics, player interactions and gameplay behaviour.

🕹️ How to Play

1. Open the game using the live demo link.
2. Click Start Pouring to begin.
3. Watch the moving nozzle.
4. Tap or click anywhere on the game area when the nozzle is positioned over the cup.
5. Complete all six pours to finish the game.

Controls:

* Mouse: Click anywhere on the game area.
* Keyboard: Press the Spacebar.

🚀 Running Locally

1. Clone this repository:

git clone <https://emeraldkingg.github.io/fiji-ice-slush-tap/>

2. Navigate into the project folder:

cd fiji-ice-slush-tap

3. Open index.html in your browser.

No additional dependencies or installations are required.
